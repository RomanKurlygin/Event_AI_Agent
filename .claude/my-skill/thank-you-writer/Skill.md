# Thank You Writer Skill

Доменный навык для благодарностей после мероприятия.

## When to Use

- Спасибо гостям после праздника
- Благодарность подрядчикам и команде
- Короткий пост или email благодарности

## Source of Truth

- `skills/event-planner/agents/thank-you-writer-agent.md`

## Key Outputs

- `thank_you.variants` — guests_short, guests_warm, vendors, team
- `thank_you.personalization_tips[]`
- `thank_you.send_within_days`

## Rules

- Тон по event_type (wedding — тёплый, corporate — нейтральный)
- Без просьб о подарках
- Отправить в течение 1–7 дней после события
