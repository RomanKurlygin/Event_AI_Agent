# Feedback Survey Skill

Доменный навык для опроса гостей после мероприятия.

## When to Use

- Опрос удовлетворённости, feedback, NPS
- Вопросы для Google Forms / Яндекс.Форм
- Сбор отзывов после корпоратива / конференции

## Source of Truth

- `skills/event-planner/agents/feedback-survey-agent.md`

## Key Outputs

- `feedback_survey.intro`, `thank_you_message`
- `feedback_survey.questions[]` — scale, open, nps, choice
- `feedback_survey.distribution_tips[]`

## Rules

- short: 5–7 вопросов; standard: 8–12; detailed: 13–18
- Не более 3 open-вопросов
- Вопросы адаптировать под event_type
