# /plan

Создай план реализации для текущей фичи.

## Шаги

1. Прочитай PRD из `docs/prds/` (уточни у пользователя, какой)
2. Прочитай `docs/architecture/SYSTEM.md`
3. Создай или обнови `docs/plans/[feature]-plan.md` с фазами:
   - Requirements review
   - MD prompts update (skills/event-planner/)
   - Code implementation (если нужен runtime)
   - Tests
   - Validation
4. Укажи validation command из `PROJECT.md`

## Output

Структурированный план с чеклистом задач и зависимостями.
