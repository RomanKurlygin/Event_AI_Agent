# MEMORY.md — Стратегия памяти EventGenie

## Что запоминается

| Данные | Хранилище | Срок |
|--------|-----------|------|
| Профиль пользователя | `USER.md` | постоянно |
| История событий | `USER.md` + `memory/YYYY-MM-DD.md` | постоянно |
| Предпочтения (стиль планов, валюта) | `USER.md` | постоянно |
| Решения и уроки | `MEMORY.md` | курируется |
| Сырые логи сессий | `memory/YYYY-MM-DD.md` | 90 дней |

## Профиль события (шаблон)

```json
{
  "event_name": "Свадьба Ивана и Марии",
  "event_type": "wedding",
  "event_date": "2026-04-15T18:00:00",
  "location": "Москва",
  "expected_guests": 150,
  "budget_limit": 1000000,
  "format": "offline | hybrid | online",
  "target_audience": "Молодые пары 25-35 лет"
}
```

## Уровни приоритета задач

| Priority | Значение | Пример |
|----------|----------|--------|
| CRITICAL | Без этого событие не состоится | Бронь площадки |
| HIGH | Сильно влияет на качество | Кейтеринг, ведущий |
| MEDIUM | Важно, но есть альтернативы | Декор, фотограф |
| LOW | Nice-to-have | Подарки гостям, фотозона |

## Правило обновления после сессии

1. Записать ключевые решения в `memory/YYYY-MM-DD.md`
2. Обновить таблицу событий в `USER.md`
3. Раз в несколько сессий — пересмотреть `MEMORY.md`, убрать устаревшее

## Категории бюджета (базовый набор)

- Площадка
- Кейтеринг
- Развлечения (DJ, ведущий, артисты)
- Декор и цветы
- Фото / видео
- Техника (звук, свет, экран)
- Транспорт
- Прочее (приглашения, подарки, резерв 10–15%)
