AI Event Planner

EventGenie

Многоагентный AI-помощник для планирования мероприятий: один запрос — план, бюджет, приглашения, риски и контент для соцсетей.

Markdown-first OpenClaw Multi-agent VK / Dashboard

«Расскажи о событии — и я составлю план, задачи и смету.»

Проблема

Организация события — это хаос

📋 Разрозненность

План в Excel, бюджет в заметках, гости в чате, приглашения в Canva — нет единой картины.

⏱ Нехватка времени

Организатор тратит десятки часов на шаблоны, чек-листы и пересчёт сметы вручную.

💸 Ошибки в бюджете

Забытые статьи расходов, нет резерва 10–15%, сложно оптимизировать без опыта.

🎯 День X

Нет run-of-show, рисков и plan B — команда не знает «кто, где, когда».

Решение

Один агент — весь цикл подготовки

🎯 EventGenie

AI-планировщик, который понимает тип события, дату, гостей и бюджет — и выдаёт структурированный результат.

🧠 Maestro

Оркестратор определяет намерение (план? смета? приглашение?) и направляет к нужному специалисту.

📝 Markdown-first

Поведение агентов живёт в .md файлах — прозрачно, версионируется в Git, легко расширять.

💬 Любой канал

Dashboard OpenClaw, VK-бот, Cursor — один и тот же EventGenie, разные точки входа.

Технологии

Стек проекта

Runtime

  • OpenClaw Gateway — сервер агента
  • OpenRouter — основная LLM
  • MiniMax — fallback / image-01
  • @openclaw-vk/vk — канал ВКонтакте

Архитектура

  • Markdown-first промпты
  • PRD-driven разработка
  • Intent routing через Maestro
  • Node.js 20+, npm

Артефакты

  • output/invitations/ — HTML-карточки
  • output/images/ — сгенерированные картинки
  • docs/prds/ — требования к фичам

Домен

Типы событий

💒 wedding

Церемония, банкет, 50–300 гостей. Торжественный тон, риски outdoor.

🎂 birthday

Вечеринка, детский праздник. Тёплый тон, торт, развлечения.

🏢 corporate

Тимбилдинг, корпоратив. Нейтральный тон, AV, брендинг.

🎤 conference

Доклады, нетворкинг, гибрид. Agenda, спикеры, Wi‑Fi.

Агенты адаптируют шаблоны, тон и чек-листы под event_type.
