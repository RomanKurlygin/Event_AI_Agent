# Демо-сообщения EventGenie

Готовые фразы для VK, Dashboard или Cursor — по одному запросу на каждый скилл.

**Тестовое событие (можно копировать контекст):**
- Свадьба Ивана и Марии
- 20 августа 2026, 16:00
- Москва, ресторан «Панорама»
- 100 гостей, бюджет 1 500 000 ₽

Перед демо: `.\scripts\start-gateway.ps1` (окно не закрывать).

## 1. Planning — план подготовки

```
Составь план подготовки свадьбы Ивана и Марии: 20 августа 2026, Москва, 100 гостей. Нужен таймлайн и чек-лист задач с приоритетами.
```

**Ожидается:** фазы подготовки, задачи с CRITICAL/HIGH, дедлайны в днях до события.

---

## 2. Finance — бюджет

```
Посчитай смету свадьбы на 100 гостей, бюджет 1 500 000 ₽, Москва, 20 августа 2026. Разбей по категориям и дай рекомендации.
```

**Ожидается:** категории (площадка, кейтеринг…), итого, резерв 10%, анализ.

---

## 3. Full event planning — план + бюджет

```
Нужен полный пакет: план и бюджет свадьбы Ивана и Марии, 20.08.2026, Москва, 100 гостей, лимит 1,5 млн ₽.
```

**Ожидается:** Maestro вызывает planning + finance, резюме в начале.

---

## 4. Run-of-show — программа дня

```
Сделай run-of-show на день свадьбы: старт 16:00, 100 гостей, церемония + банкет ~5 часов. Программа по минутам с ответственными.
```

**Ожидается:** таблица cues (время, активность, owner, заметки), plan B.

---

## 5. Guest list — гости и RSVP

```
Составь список гостей на свадьбу: 100 человек, 10 столов, 5 детей. Шаблон RSVP и план рассадки.
```

**Ожидается:** summary, таблица гостей, рассадка, next steps.

---

## 6. Invitation — текст приглашения

```
Напиши текст приглашения на свадьбу Ивана и Марии, 20 августа 2026, 16:00, Москва, ресторан Панорама. Короткий для WhatsApp и развёрнутый для email.
```

**Ожидается:** short + formal, checklist перед отправкой.

---

## 7. Invitation — HTML-карточка

```
Сделай HTML-карточку приглашения на свадьбу Ивана и Марии, 20 августа 2026, 16:00, Москва, ресторан Панорама. Используй шаблон invitation и тему wedding-elegant. Сохрани в output/invitations/.
```

**Ожидается:** путь к `.html`, подсказка открыть в браузере.

> **VK:** агент может описать файл; открыть HTML нужно на ПК. Для VK удобнее пост + картинка (скиллы 8–9).

---

## 8. Image generator — картинка / баннер

```
Сгенерируй баннер для VK: свадьба Ивана и Марии, 20 августа 2026, элегантные цветы, золото, без текста на картинке. Формат 16:9.
```

**Ожидается:** `output/images/...png`, промпт, подсказка для VK.

---

## 9. Social posts — посты для соцсетей

```
Напиши посты для VK про свадьбу Ивана и Марии, 20 августа 2026, Москва: анонс, countdown за 7 и 1 день, напоминание. Добавь хештеги и график публикаций.
```

**Ожидается:** тексты постов, hashtags, posting_schedule.

---

## 10. Risk checklist — риски

```
Какие риски на свадьбе 20 августа в Москве, 100 гостей, часть программы на открытом воздухе? Нужен чек-лист с plan B.
```

**Ожидается:** таблица рисков, top priorities, проверки за 7/3/1 день.

---

## 11. Feedback survey — опрос после события

```
Составь опрос для гостей после свадьбы: 10–12 вопросов, шкалы и 1–2 открытых. Вступление и текст благодарности после опроса.
```

**Ожидается:** intro, questions[], thank_you_message, как разослать.

---

## 12. Thank you — благодарность после

```
Напиши благодарность гостям после свадьбы Ивана и Марии: короткий пост для VK и тёплый развёрнутый вариант. Упомяни атмосферу и танцы.
```

**Ожидается:** guests_short, guests_warm, personalization_tips.

## Один сценарий «за 3 сообщения» (быстрое демо)

**Сообщение 1:**
```
Полный план и бюджет: свадьба Ивана и Марии, 20.08.2026, Москва, 100 гостей, 1 500 000 ₽
```

**Сообщение 2:**
```
Текст приглашения + пост-анонс для VK на это же событие
```

**Сообщение 3:**
```
Риски и run-of-show на день свадьбы, старт 16:00
```

## Если агент путает intent

Добавь явное ключевое слово из таблицы в `skills/event-planner/SKILL.md`:

- план / бюджет / run-of-show / гости / приглашение / карточка / риски / пост / опрос / спасибо / баннер / картинка

Пример: *«Не план, а именно **смета** на 100 гостей»*.

---

## Ограничения при демо

| Ситуация | Что делать |
|----------|------------|
| Rate limit OpenRouter | Подождать 1–2 мин, новый запрос |
| HTML/PNG в VK | Файлы на ПК в `output/`; в VK придёт текст + инструкция |
| Gateway выключен | `.\scripts\start-gateway.ps1` |
| Бот не отвечает | Проверить pairing, `channels status --probe` |
